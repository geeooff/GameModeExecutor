# Recipes

Worked examples, one folder each: the steps and a complete `config.toml` to
copy over your own. Each release also carries them as
`GameModeExecutor-recipes-<version>.zip`. Set the program up first with
[Getting started](../getting-started.md).

| Recipe | What it does | Comes with |
| --- | --- | --- |
| [Fan profiles with FanControl](fancontrol-fan-profiles/) | Quiet fan curves outside games, gaming ones while playing; the way to run a program that needs administrator rights. | `config.toml`, two task templates, install scripts |
| [Windows power plan](windows-power-plan/) | High performance while playing, balanced otherwise; the simple shape most commands have. | `config.toml` |

For your own commands, the starter configuration's comments and the
[reference](../reference.md#actions) list every field and placeholder.

## Adding one

A folder with a `README.md`, usually a `config.toml` beside it, and a row in
the table above.
